简单编程，就是有很多一层一层的web目录，只有一条通往最深处，找到对的那条调试过程，因为网络不好不定时 500 加了个异常处理

import requests
import re

url = “https://depth.q.2023.ugractf.ru/4s026iq4j980bzas/“
r = requests.get(url)

reg1 = re.findall(‘‘,r.text)
for a in range(0,10000):
    try:
        for i in reg1:
            tmp_url = url
            i = i.replace(“<A HREF=”,””)
            i = i.replace(“/>”,””)
            tmp_url = tmp_url + i + “/“
            r2 = requests.get(tmp_url)
            if “HREF” in r2.text:
                url = tmp_url
                reg1 = re.findall(‘‘,r2.text)
                print(url+”n”)
                break
    
except:
        pass
