Unsafe Parameters – 共享私钥指数的RSA攻击

题目信息

题目描述：多点n真的会更安全吗，我有种不好的预感……（Is having more n really safer? I have a bad feeling）

知识点：RSA、共享私钥攻击、LLL格基规约算法

一、题目分析

1.1 题目代码解析

首先，我们来看题目给出的加密代码（task.py）：

fromCrypto.Util.numberimportfromCrypto.Util.PaddingimportpadfromCrypto.CipherimportAESfromhashlibimportsha3_512fromsecretimportdefgenParams(): ns = [] es = [] ps = [] d = getPrime(425) # 生成一个425位的素数作为私钥指数 for_in’flag{‘: # 循环5次（’flag{‘有5个字符） p, q, r = [getPrime(512)for_inrange(3)] # 生成3个512位素数 ps.append((p, q, r)) n = p * q * r # n是三个素数的乘积 totient = (p -1) * (q -1) * (r -1) # 计算欧拉函数 es.append(inverse(d, totient)) # e是d在模totient下的逆元 ns.append(n) return(ns, es), (d, ps)

1.2 加密流程分析

让我们逐步分析这个加密过程：

生成唯一的私钥指数d：程序首先生成一个425位的素数d，这将作为所有RSA系统的共享私钥指数

生成5组RSA参数：循环5次，每次执行以下操作：

生成3个512位的素数 p、q、r

计算模数n = p × q × r（约1536位）

计算欧拉函数φ(n) = (p-1) × (q-1) × (r-1)

计算公钥指数e = d^(-1) mod φ(n)

AES密钥生成：

将所有素数求和：sum = Σ(p + q + r)

使用SHA3-512哈希后取前16字节作为AES密钥

用AES-ECB模式加密flag

e_i是已知的公钥指数

d是未知的共享私钥指数（我们要求的）

k_i是未知的整数系数

φ(n_i)近似等于n_i（因为p、q、r都是大素数）

格（Lattice）可以想象成多维空间中的一个点阵

LLL算法能帮我们在这个点阵中找到长度较短的向量

我们可以构造一个特殊的格，使得”短向量”恰好包含我们想要的d

M = 2^1024是一个大数（用于平衡）

e_i是各个公钥指数

n_i是各个模数

创建6×6的格矩阵

使用LLL算法找到短向量（Mat.LLL()）

规约后的矩阵第一行通常包含最短向量

从短向量的第一个分量除以M得到d

由于e × d ≡ 1 (mod φ(n))，所以e × d - 1是φ(n)的倍数

设e × d - 1 = 2^s × t（其中t是奇数）

对随机选择的g，计算g^t, g^(2t), g^(4t), …

当某个值减1后与n的最大公约数不为1且不为n时，我们找到了n的一个因子

不同的RSA系统必须使用不同的密钥对

本题错误地在多个RSA系统中共享了私钥指数d

这创造了可被利用的数学关系

密钥生成的独立性

每个RSA密钥对都应该独立生成

即使是相关的系统，也不应共享任何密钥材料

共享私钥攻击（如本题）

低加密指数攻击（如e=3的广播攻击）

Coppersmith攻击（当部分明文已知时）

背包密码攻击

分解难度理论上更高

相同安全级别下n可以更小

计算效率降低

实际安全性提升有限

如果实现不当（如本题），反而引入新漏洞

私钥d的特征：

比特长度：425 bits（符合题目设定）

是素数：True（验证通过）

LLL算法从规约后矩阵的第3行成功提取

模数分解结果：

每个n成功分解为3个512位的素数

总共分解出15个素数（5组，每组3个）

所有素数的比特长度都正确（512 bits）

最终验证：

成功解密AES密文

获得格式正确的flag

完整攻击流程验证成功

如果只有3组RSA系统共享d，LLL攻击是否仍然有效？

可能有效，但成功率会降低。LLL攻击的成功率与方程组数量相关。

如果每个n使用不同的e值，但仍共享d，攻击是否仍然可行？

是的，仍然可行。关键漏洞是共享d，而不是e的选择。

如果加密指数e很小（如e=3），但每个系统使用不同的d，会有什么问题？

如果对相同明文加密多次，可能遭受Håstad广播攻击。

漏洞本质：多个RSA系统共享私钥指数d创造了可利用的数学关系

攻击方法：利用LLL格基规约算法从公开参数中恢复共享的私钥

数学原理：e_i × d ≈ k_i × n_i这一近似关系是攻击的基础

安全教训：密钥独立性是密码系统安全的基本原则

RSA的安全性建立在大数分解的困难性上

但如果实现不当，数学关系会泄露密钥信息

LLL算法是格密码学中的强大工具

理解攻击原理有助于构建更安全的系统
